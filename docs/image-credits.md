# Destination image credits

SafariSmart uses real photographs from Wikimedia Commons for the five curated destination cards. The local assets are resized, center-cropped to a 16:9 presentation, converted to WebP, and stripped of embedded metadata for web delivery. Those transformations are modifications of the credited originals; no generative imagery is used.

Each card displays its photographer and license beside the photograph. The source and license links below provide the complete attribution record.
